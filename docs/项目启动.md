先装 Node.js，再分别启动后端和前端就行。你现在项目已经是前后端分离结构，运行顺序如下。

先确保你本机装了 Node.js 20 LTS，然后在 E:\autoIssue 打开终端执行：

npm install
接着先配后端环境变量。把 apps/server/.env.example 复制一份为 apps/server/.env，内容可以先用这个：

PORT=3000
DB_PATH=./storage/app.db
APP_SECRET=please-change-me
然后启动后端：

npm run dev:server
看到类似 listening on http://localhost:3000 就说明后端起来了。再开第二个终端，还是在 E:\autoIssue 下启动前端：

npm run dev:web
前端默认地址是：

http://localhost:5173
你打开浏览器访问这个地址，就能看到后台页面。

如果你想更稳一点，按这个顺序检查：

先执行 node -v 和 npm -v，确认环境装好了。
再执行 npm install。
再启动后端 npm run dev:server。
最后启动前端 npm run dev:web。
